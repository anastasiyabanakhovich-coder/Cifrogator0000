ЦИФРОГАТОР — космическая версия

Загрузите ВСЕ файлы и папку assets в корень GitHub Pages.
Главная: index.html; выбор возраста: age.html; квест: game.html.
Робот создан на CSS, следит глазами за курсором, машет рукой. Подсказка появляется при наведении/фокусе или нажатии.
Космическая музыка генерируется Web Audio API и включается кнопкой «Музыка» — браузеры запрещают автоматическое воспроизведение до взаимодействия пользователя.
Звуки заданий переключаются отдельной кнопкой. Прогресс хранится локально в браузере.
